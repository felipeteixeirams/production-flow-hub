# Production Flow Hub

Transforme esse protótipo visual em uma página navegável, o sistema é voltado a uso em tablet, as imagens que mandei é a mesma tela, mas com o tablet na vertical e ele na horizontal, se a tela for reduzida não deve sofrer com deformações, só algumas modificações, onde tem "FLUXO DE PRODUÇÃO" nós vamos usar para botões de ações rápidas para permitir o operador cadastrar uma Produção Avulsa, ver a lista completa equipamentos como esqueletos (carrinhos abertos), estufas, fornos e se estão em uso ou não, se estiver em uso precisam dizer a quantidade de pães que tem no equipamento naquele momento, o tipo do produto como "Pão Francês" e a etapa que está ocorrendo ali como "Assando"/"Fermentação"/"Esqueleto"/"Descongelamento" e os equipamentos livres,  os botões sincronizado e atualizar no topo direito poderiam ser mais sutis e menores, falta um botão para deslogar o operador, outro botão de ação rápida são para registrar Ocorrência do tipo descarte/ruptura/exceção e motivo como queima no forno/falta de insumo/falha de energia/contaminação etc,  e Manutenção seria para registrar a suspensão algum equipamento ou registar a volta da operação de algum equipamento que estava em manutenção.
